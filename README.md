
# CSS Advanced — Week 2 Day 1

## 📌 Overview

This project demonstrates advanced CSS techniques for creating polished and interactive user interfaces. It includes CSS custom properties, dark/light theme switching, animations, pseudo-elements, smooth scrolling, and sticky navigation.

## 🎯 Learning Objectives

- Use CSS custom properties to maintain consistent styles.
- Implement a dark/light theme switcher.
- Create a CSS-only loading spinner and animated progress bar.
- Use `::before` and `::after` pseudo-elements.
- Apply smooth scrolling and sticky navigation.
- Use CSS transitions and animations to improve user experience.
- Create responsive layouts using modern CSS techniques.

## ✨ Features

### 1. CSS Custom Properties
Uses reusable CSS variables for colors, spacing, border radius, shadows, and transitions.

### 2. Dark/Light Theme Switcher
Switches between light and dark themes using CSS custom properties and a JavaScript click event.

### 3. Loading Spinner
Uses CSS `@keyframes` to create a continuously rotating loading animation without external libraries.

### 4. Animated Progress Bar
Displays a progress bar that animates from 0% to 75%.

### 5. Pseudo-elements
Uses `::before` and `::after` to add decorative elements without additional HTML markup.

### 6. Sticky Navigation
Keeps the navigation bar visible while scrolling using `position: sticky`.

### 7. Smooth Scrolling
Uses `scroll-behavior: smooth` to provide smooth navigation between page sections.

### 8. Responsive Design
Uses CSS Grid, flexible layouts, relative units, and media queries to support different screen sizes.

### 9. Accessibility
Includes accessible labels and reduced-motion support for users who prefer fewer animations.

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Click **Toggle Theme** to switch between light and dark modes.
5. Scroll through the page to test the navigation, spinner, progress bar, and hover effects.
